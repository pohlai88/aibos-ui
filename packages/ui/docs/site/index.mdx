# AIBOS UI Design System

A comprehensive, enterprise-grade component library built for the AI-BOS ERP system. Built with React, TypeScript, and Tailwind CSS for maximum performance and developer experience.

## Import

```tsx
import { Button, Card, Input, Modal, Table } from '@aibos/ui';
```

## Basic Usage

```tsx
import { Button, Card, Input } from '@aibos/ui';

function App() {
  return (
    <Card>
      <CardHeader>
        <CardTitle>Welcome to AIBOS ERP</CardTitle>
        <CardDescription>Enter your information to get started</CardDescription>
      </CardHeader>
      <CardContent>
        <div className="space-y-4">
          <Input placeholder="Enter your name" />
          <Input type="email" placeholder="Enter your email" />
        </div>
      </CardContent>
      <CardFooter>
        <Button variant="primary">Get Started</Button>
      </CardFooter>
    </Card>
  );
}
```

## Design Principles

### 1. Semantic Tokens Only

All components use semantic design tokens instead of hardcoded values for maximum maintainability and consistency.

```tsx
// ✅ Good - Semantic tokens
<Button className="bg-semantic-primary text-semantic-primary-foreground hover:bg-semantic-primary/90" />

// ❌ Bad - Hardcoded colors
<Button className="bg-blue-600 text-white hover:bg-blue-700" />
```

### 2. Polymorphic Support

All components support polymorphic behavior via the `as` prop for maximum flexibility.

```tsx
// Render as different elements
<Button as="a" href="/link">Link Button</Button>
<Button as="div" onClick={handleClick}>Div Button</Button>
<Button as={CustomComponent} customProp="value">Custom Component</Button>
```

### 3. Accessibility First

All components meet WCAG 2.1 AA standards with proper ARIA attributes and keyboard navigation.

```tsx
// Automatic accessibility features
<Button aria-label="Close dialog">×</Button>
<Input aria-describedby="email-help" />
<div id="email-help">Enter your email address</div>
```

### 4. Tree-Shaking Optimized

Import only what you need for optimal bundle size and performance.

```tsx
// ✅ Optimal - Individual imports
import { Button } from '@aibos/ui/primitives/button';
import { Card } from '@aibos/ui/components/card';

// ✅ Good - Main import (still tree-shakable)
import { Button, Card } from '@aibos/ui';

// ❌ Avoid - Importing from source files
import { Button } from '@aibos/ui/src/primitives/button';
```

## Usage Guidelines

### Component Development

Follow these guidelines when developing with AIBOS UI components:

```tsx
// ✅ Proper component usage
function UserProfile() {
  return (
    <Card>
      <CardHeader>
        <CardTitle>User Profile</CardTitle>
        <CardDescription>Manage your account settings</CardDescription>
      </CardHeader>
      <CardContent>
        <Form onSubmit={handleSubmit}>
          <FormField name="name" label="Full Name" required />
          <FormField name="email" type="email" label="Email" required />
          <Button type="submit">Save Changes</Button>
        </Form>
      </CardContent>
    </Card>
  );
}
```

**Development Rules:**

- Use semantic tokens only
- Support polymorphic behavior
- Include comprehensive tests
- Document all props and variants

### Import Strategy

Optimize your imports for better bundle size and performance:

```tsx
// ✅ Tree-shakable imports
import { Button } from '@aibos/ui/primitives/button';
import { Card, CardHeader, CardTitle } from '@aibos/ui/components/card';

// ✅ Main import (still optimized)
import { Button, Card, Input, Modal } from '@aibos/ui';

// ❌ Avoid source imports
import { Button } from '@aibos/ui/src/primitives/button';
```

**Import Best Practices:**

- Prefer tree-shakable imports
- Use individual exports for optimal bundling
- Avoid importing from source files

### Testing Standards

Ensure comprehensive testing for all components:

```tsx
// ✅ Comprehensive test example
import { render, screen, fireEvent } from '@testing-library/react';
import { axe, toHaveNoViolations } from 'jest-axe';

test('Button accessibility', async () => {
  const { container } = render(<Button>Test Button</Button>);
  const results = await axe(container);
  expect(results).toHaveNoViolations();
});
```

**Testing Requirements:**

- Test all variants and states
- Include accessibility tests
- Test polymorphic behavior
- Cover edge cases
