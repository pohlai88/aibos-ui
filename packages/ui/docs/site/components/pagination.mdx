# Pagination

Page navigation components for navigating through large datasets and content.

## Import

```tsx
import {
  Pagination,
  PaginationContent,
  PaginationEllipsis,
  PaginationItem,
  PaginationLink,
  PaginationNext,
  PaginationPrevious,
} from '@aibos/ui';
```

## Basic Usage

```tsx
<Pagination>
```

## Form Integration

### Controlled Pagination

```tsx
function ControlledPagination() {
  const [currentPage, setCurrentPage] = useState(1);
  const totalPages = 10;

  const handlePageChange = (page) => {
    setCurrentPage(page);
  };

  return (
    <Pagination>
      <PaginationContent>
        <PaginationItem>
          <PaginationPrevious
            href="#"
            onClick={() => handlePageChange(currentPage - 1)}
            disabled={currentPage === 1}
          />
        </PaginationItem>

        {Array.from({ length: totalPages }, (_, i) => i + 1).map((page) => (
          <PaginationItem key={page}>
            <PaginationLink
              href="#"
              onClick={() => handlePageChange(page)}
              isActive={page === currentPage}
            >
              {page}
            </PaginationLink>
          </PaginationItem>
        ))}

        <PaginationItem>
          <PaginationNext
            href="#"
            onClick={() => handlePageChange(currentPage + 1)}
            disabled={currentPage === totalPages}
          />
        </PaginationItem>
      </PaginationContent>
    </Pagination>
  );
}
```

### Dynamic Pagination

```tsx
function DynamicPagination() {
  const [currentPage, setCurrentPage] = useState(1);
  const [totalPages, setTotalPages] = useState(5);

  const addPages = () => {
    setTotalPages(totalPages + 5);
  };

  const removePages = () => {
    if (totalPages > 1) {
      setTotalPages(totalPages - 1);
    }
  };

  return (
    <div className="space-y-4">
      <div className="flex items-center justify-between">
        <h3 className="text-lg font-semibold">Dynamic Pagination</h3>
        <div className="flex items-center space-x-2">
          <Button onClick={removePages} variant="outline" size="sm">
            Remove Page
          </Button>
          <Button onClick={addPages} size="sm">
            Add Pages
          </Button>
        </div>
      </div>

      <Pagination>
        <PaginationContent>
          <PaginationItem>
            <PaginationPrevious
              href="#"
              onClick={() => setCurrentPage(currentPage - 1)}
              disabled={currentPage === 1}
            />
          </PaginationItem>

          {Array.from({ length: totalPages }, (_, i) => i + 1).map((page) => (
            <PaginationItem key={page}>
              <PaginationLink
                href="#"
                onClick={() => setCurrentPage(page)}
                isActive={page === currentPage}
              >
                {page}
              </PaginationLink>
            </PaginationItem>
          ))}

          <PaginationItem>
            <PaginationNext
              href="#"
              onClick={() => setCurrentPage(currentPage + 1)}
              disabled={currentPage === totalPages}
            />
          </PaginationItem>
        </PaginationContent>
      </Pagination>
    </div>
  );
}
```

## Accessibility

- **Keyboard Navigation**: Full keyboard support for navigation
- **Screen Reader Support**: Proper ARIA attributes and announcements
- **Focus Management**: Clear focus indicators
- **Page Context**: Clear indication of current page and total pages
- **Navigation State**: Proper indication of disabled states

## Best Practices

1. **Use clear labels** - Provide descriptive page numbers and navigation
2. **Handle edge cases** - Manage first/last page states properly
3. **Consider mobile devices** - Provide mobile-friendly pagination
4. **Show page context** - Display current page and total pages
5. **Test with screen readers** - Ensure accessibility compliance
6. **Use appropriate spacing** - Maintain consistent spacing between elements
