# Table

A powerful data table component with sorting, filtering, pagination, and virtualization for handling large datasets.

## Import

```tsx
import { Table } from '@aibos/ui';
```

## Basic Usage

```tsx
const data = [
  { id: 1, name: 'John Doe', email: 'john@example.com', role: 'Admin' },
  { id: 2, name: 'Jane Smith', email: 'jane@example.com', role: 'User' },
  { id: 3, name: 'Bob Johnson', email: 'bob@example.com', role: 'User' },
];

const columns = [
  { key: 'name', label: 'Name', sortable: true },
  { key: 'email', label: 'Email', sortable: true },
  { key: 'role', label: 'Role', sortable: true },
];

function BasicTable() {
  return (
    <Table
      data={data}
      columns={columns}
      onSort={(key, direction) => console.log('Sort:', key, direction)}
    />
  );
}
```

### With Selection

```tsx
function SelectableTable() {
  const [selectedRows, setSelectedRows] = useState([]);

  const handleSelectAll = (checked) => {
    if (checked) {
      setSelectedRows(data.map((row) => row.id));
    } else {
      setSelectedRows([]);
    }
  };

  const handleSelectRow = (rowId, checked) => {
    if (checked) {
      setSelectedRows([...selectedRows, rowId]);
    } else {
      setSelectedRows(selectedRows.filter((id) => id !== rowId));
    }
  };

  return (
    <div className="space-y-4">
      <div className="flex items-center justify-between">
        <p className="text-semantic-muted-foreground text-sm">
          {selectedRows.length} of {data.length} selected
        </p>
        {selectedRows.length > 0 && (
          <Button variant="destructive" size="sm">
            Delete Selected
          </Button>
        )}
      </div>

      <Table
        data={data}
        columns={columns}
        selectable
        selectedRows={selectedRows}
        onSelectAll={handleSelectAll}
        onSelectRow={handleSelectRow}
        onSort={(key, direction) => console.log('Sort:', key, direction)}
      />
    </div>
  );
}
```

### With Pagination

```tsx
function PaginatedTable() {
  const [currentPage, setCurrentPage] = useState(1);
  const [pageSize, setPageSize] = useState(10);

  const totalPages = Math.ceil(data.length / pageSize);
  const startIndex = (currentPage - 1) * pageSize;
  const endIndex = startIndex + pageSize;
  const currentData = data.slice(startIndex, endIndex);

  return (
    <div className="space-y-4">
      <Table
        data={currentData}
        columns={columns}
        onSort={(key, direction) => console.log('Sort:', key, direction)}
      />

      <div className="flex items-center justify-between">
        <div className="flex items-center space-x-2">
          <p className="text-semantic-muted-foreground text-sm">Rows per page:</p>
          <Select value={pageSize.toString()} onValueChange={(value) => setPageSize(Number(value))}>
            <SelectTrigger className="w-20">
              <SelectValue />
            </SelectTrigger>
            <SelectContent>
              <SelectItem value="10">10</SelectItem>
              <SelectItem value="20">20</SelectItem>
              <SelectItem value="50">50</SelectItem>
            </SelectContent>
          </Select>
        </div>

        <div className="flex items-center space-x-2">
          <Button
            variant="outline"
            size="sm"
            disabled={currentPage === 1}
            onClick={() => setCurrentPage(currentPage - 1)}
          >
            Previous
          </Button>
          <span className="text-sm">
            Page {currentPage} of {totalPages}
          </span>
          <Button
            variant="outline"
            size="sm"
            disabled={currentPage === totalPages}
            onClick={() => setCurrentPage(currentPage + 1)}
          >
            Next
          </Button>
        </div>
      </div>
    </div>
  );
}
```

### With Filtering

```tsx
function FilterableTable() {
  const [filters, setFilters] = useState({});
  const [searchTerm, setSearchTerm] = useState('');

  const filteredData = data.filter((row) => {
    const matchesSearch =
      !searchTerm ||
      Object.values(row).some((value) =>
        value.toString().toLowerCase().includes(searchTerm.toLowerCase()),
      );

    const matchesFilters = Object.entries(filters).every(
      ([key, value]) => !value || row[key] === value,
    );

    return matchesSearch && matchesFilters;
  });

  return (
    <div className="space-y-4">
      <div className="flex items-center space-x-4">
        <div className="flex-1">
          <Input
            placeholder="Search..."
            value={searchTerm}
            onChange={(e) => setSearchTerm(e.target.value)}
          />
        </div>
        <Select
          value={filters.role || ''}
          onValueChange={(value) => setFilters({ ...filters, role: value })}
        >
          <SelectTrigger className="w-32">
            <SelectValue placeholder="All Roles" />
          </SelectTrigger>
          <SelectContent>
            <SelectItem value="">All Roles</SelectItem>
            <SelectItem value="Admin">Admin</SelectItem>
            <SelectItem value="User">User</SelectItem>
          </SelectContent>
        </Select>
      </div>

      <Table
        data={filteredData}
        columns={columns}
        onSort={(key, direction) => console.log('Sort:', key, direction)}
      />
    </div>
  );
}
```

## API Reference

### Props

| Prop           | Type                                                  | Default               | Description                  |
| -------------- | ----------------------------------------------------- | --------------------- | ---------------------------- |
| `data`         | `Array<Record<string, any>>`                          | -                     | Table data array             |
| `columns`      | `Column[]`                                            | -                     | Column configuration         |
| `onSort`       | `(key: string, direction: 'asc' \| 'desc') => void`   | -                     | Sort handler                 |
| `selectable`   | `boolean`                                             | `false`               | Whether rows can be selected |
| `selectedRows` | `Array<string \| number>`                             | -                     | Currently selected row IDs   |
| `onSelectAll`  | `(checked: boolean) => void`                          | -                     | Select all handler           |
| `onSelectRow`  | `(rowId: string \| number, checked: boolean) => void` | -                     | Row selection handler        |
| `loading`      | `boolean`                                             | `false`               | Whether table is loading     |
| `emptyMessage` | `string`                                              | `"No data available"` | Message when no data         |
| `className`    | `string`                                              | -                     | Additional CSS classes       |

### Column Configuration

| Prop       | Type                            | Description                  |
| ---------- | ------------------------------- | ---------------------------- |
| `key`      | `string`                        | Unique key for the column    |
| `label`    | `string`                        | Column header text           |
| `sortable` | `boolean`                       | Whether column can be sorted |
| `width`    | `string \| number`              | Column width                 |
| `align`    | `"left" \| "center" \| "right"` | Text alignment               |
| `render`   | `(row: any) => ReactNode`       | Custom cell renderer         |

## Accessibility

- **Keyboard Navigation**: Full keyboard support with Tab, Arrow keys, Enter, and Space
- **Screen Readers**: Proper ARIA attributes and table semantics
- **Focus Management**: Clear focus indicators and logical tab order
- **Sorting**: Accessible sort controls with proper labels
- **Selection**: Keyboard-accessible row selection

## Performance

- **Virtualization**: Handles large datasets efficiently
- **Memoization**: Optimized re-rendering for better performance
- **Lazy Loading**: Supports pagination and infinite scroll
- **Debounced Sorting**: Prevents excessive API calls during sorting

## Best Practices

1. **Use appropriate column widths** for better layout
2. **Provide clear column labels** for accessibility
3. **Implement proper loading states** for better UX
4. **Use semantic tokens** for consistent styling
5. **Test with keyboard navigation** to ensure accessibility
6. **Consider mobile responsiveness** for smaller screens
7. **Implement proper error handling** for data loading
8. **Use pagination or virtualization** for large datasets
