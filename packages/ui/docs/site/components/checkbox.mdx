# Checkbox

Binary choice controls for selecting one or more options from a list.

## Import

```tsx
import { Checkbox } from '@aibos/ui';
```

## Basic Usage

```tsx
<Checkbox>Accept terms and conditions</Checkbox>
```

## Variants

### Default Checkbox

```tsx
<Checkbox>Default checkbox</Checkbox>
```

### Checked State

```tsx

```

### Disabled State

```tsx

```

### Indeterminate State

```tsx

```

## Form Integration

### Controlled Checkbox

```tsx
function ControlledCheckbox() {
  const [checked, setChecked] = useState(false);

  return (
    <Checkbox checked={checked} onCheckedChange={setChecked}>
      Controlled checkbox
    </Checkbox>
  );
}
```

### Checkbox Group

```tsx
function CheckboxGroup() {
  const [selected, setSelected] = useState([]);

  const options = [
    { id: 'option1', label: 'Option 1' },
    { id: 'option2', label: 'Option 2' },
    { id: 'option3', label: 'Option 3' },
  ];

  return (
    <div className="space-y-2">
      {options.map((option) => (
        <Checkbox
          key={option.id}
          checked={selected.includes(option.id)}
          onCheckedChange={(checked) => {
            if (checked) {
              setSelected([...selected, option.id]);
            } else {
              setSelected(selected.filter((id) => id !== option.id));
            }
          }}
        >
          {option.label}
        </Checkbox>
      ))}
    </div>
  );
}
```

## API Reference

### Checkbox Props

| Prop              | Type                         | Default | Description                                    |
| ----------------- | ---------------------------- | ------- | ---------------------------------------------- |
| `checked`         | `boolean`                    | `false` | Controlled checked state                       |
| `defaultChecked`  | `boolean`                    | `false` | Uncontrolled checked state                     |
| `disabled`        | `boolean`                    | `false` | Whether the checkbox is disabled               |
| `indeterminate`   | `boolean`                    | `false` | Whether the checkbox is in indeterminate state |
| `onCheckedChange` | `(checked: boolean) => void` | -       | Callback when checked state changes            |
| `className`       | `string`                     | -       | Additional CSS classes                         |
| `children`        | `ReactNode`                  | -       | Checkbox label content                         |

## Accessibility

- **Keyboard Navigation**: Focusable with Tab key, activated with Space
- **Screen Reader Support**: Proper ARIA attributes and labels
- **Focus Management**: Visible focus indicators
- **Disabled State**: Properly announced to screen readers
- **Indeterminate State**: Correctly communicated to assistive technology

## Best Practices

1. **Use clear labels** - Provide descriptive text for each checkbox
2. **Group related options** - Use consistent spacing and grouping
3. **Handle indeterminate state** - Use for "select all" scenarios
4. **Provide feedback** - Show loading states for async operations
5. **Test with screen readers** - Ensure accessibility compliance
6. **Consider form validation** - Integrate with form validation libraries
