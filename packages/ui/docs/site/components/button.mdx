# Button

Interactive elements for user actions. Buttons are the primary way users interact with the interface.

## Import

```tsx
import { Button } from '@aibos/ui';
```

## Basic Usage

```tsx
<Button>Click me</Button>
```

## Variants

### Default Button

```tsx
<Button variant="default">Default</Button>
```

### Primary Button

```tsx
<Button variant="primary">Primary</Button>
```

### Secondary Button

```tsx
<Button variant="secondary">Secondary</Button>
```

### Destructive Button

```tsx
<Button variant="destructive">Destructive</Button>
```

### Outline Button

```tsx
<Button variant="outline">Outline</Button>
```

### Ghost Button

```tsx
<Button variant="ghost">Ghost</Button>
```

### Link Button

```tsx
<Button variant="link">Link</Button>
```

## Sizes

### Small

```tsx
<Button size="sm">Small Button</Button>
```

### Default

```tsx
<Button size="default">Default Button</Button>
```

### Large

```tsx
<Button size="lg">Large Button</Button>
```

### Icon

```tsx
<Button size="icon">🚀</Button>
```

## Polymorphic Behavior

Buttons support polymorphic behavior via the `as` prop:

```tsx
// Render as a link
<Button as="a" href="/dashboard">Go to Dashboard</Button>

// Render as a div
<Button as="div" onClick={handleClick}>Custom Element</Button>
```

## States

### Disabled

```

```

## Accessibility

Buttons are fully accessible and include:

- **Keyboard Navigation**: Focusable with Tab key
- **Screen Reader Support**: Proper ARIA labels
- **Focus Management**: Visible focus indicators
- **Disabled State**: Properly announced to screen readers

## API Reference

### Button Props

| Prop        | Type                                                                                       | Default     | Description                    |
| ----------- | ------------------------------------------------------------------------------------------ | ----------- | ------------------------------ |
| `variant`   | `'default' \| 'primary' \| 'secondary' \| 'destructive' \| 'outline' \| 'ghost' \| 'link'` | `'default'` | Visual style variant           |
| `size`      | `'sm' \| 'default' \| 'lg' \| 'icon'`                                                      | `'default'` | Size of the button             |
| `disabled`  | `boolean`                                                                                  | `false`     | Whether the button is disabled |
| `as`        | `React.ElementType`                                                                        | `'button'`  | Element type to render         |
| `className` | `string`                                                                                   | -           | Additional CSS classes         |
| `children`  | `ReactNode`                                                                                | -           | Button content                 |
| `onClick`   | `(event: MouseEvent) => void`                                                              | -           | Click handler                  |
| `type`      | `'button' \| 'submit' \| 'reset'`                                                          | `'button'`  | Button type for forms          |

## Best Practices

1. **Use semantic variants** - Choose variants that match the action's importance
2. **Provide clear labels** - Use descriptive text that explains the action
3. **Handle loading states** - Show loading indicators for async actions
4. **Use appropriate sizes** - Choose sizes that match the context
5. **Test with screen readers** - Ensure accessibility compliance
6. **Consider keyboard navigation** - Support Tab and Enter/Space keys
