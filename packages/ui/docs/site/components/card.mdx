# Card

A flexible container component for grouping related content with semantic tokens and consistent spacing.

## Import

```tsx
import { Card, CardHeader, CardTitle, CardDescription, CardContent, CardFooter } from '@aibos/ui';
```

## Basic Usage

```tsx
<Card>
  <CardHeader>
    <CardTitle>Card Title</CardTitle>
    <CardDescription>Card description goes here</CardDescription>
  </CardHeader>
  <CardContent>
    <p>Card content goes here</p>
  </CardContent>
</Card>
```

## Variants

### Default Card

```tsx
<Card>
  <CardContent>
    <p>Simple card with just content</p>
  </CardContent>
</Card>
```

### Card with Header and Footer

```tsx
<Card>
  <CardHeader>
    <CardTitle>Product Details</CardTitle>
    <CardDescription>Manage your product information</CardDescription>
  </CardHeader>
  <CardContent>
    <div className="space-y-2">
      <p>Product Name: AIBOS ERP</p>
      <p>Version: 2.0</p>
      <p>Status: Active</p>
    </div>
  </CardContent>
  <CardFooter>
    <Button variant="outline">Edit</Button>
    <Button>Save</Button>
  </CardFooter>
</Card>
```

### Card with Actions

```tsx
<Card>
  <CardHeader>
    <CardTitle>User Profile</CardTitle>
    <CardDescription>Update your profile information</CardDescription>
  </CardHeader>
  <CardContent>
    <div className="space-y-4">
      <div>
        <label className="text-sm font-medium">Name</label>
        <Input placeholder="Enter your name" />
      </div>
      <div>
        <label className="text-sm font-medium">Email</label>
        <Input type="email" placeholder="Enter your email" />
      </div>
    </div>
  </CardContent>
  <CardFooter className="justify-between">
    <Button variant="outline">Cancel</Button>
    <Button>Save Changes</Button>
  </CardFooter>
</Card>
```

## Interactive Cards

### Clickable Card

```tsx
<Card className="cursor-pointer transition-shadow hover:shadow-md">
  <CardHeader>
    <CardTitle>Project Alpha</CardTitle>
    <CardDescription>Click to view project details</CardDescription>
  </CardHeader>
  <CardContent>
    <p>Status: In Progress</p>
    <p>Team: 5 members</p>
  </CardContent>
</Card>
```

### Card with Form

```tsx
<Card>
  <CardHeader>
    <CardTitle>Create New Project</CardTitle>
    <CardDescription>Fill out the form below to create a new project</CardDescription>
  </CardHeader>
  <CardContent>
    <form className="space-y-4">
      <div>
        <label className="text-sm font-medium">Project Name</label>
        <Input placeholder="Enter project name" />
      </div>
      <div>
        <label className="text-sm font-medium">Description</label>
        <textarea
          className="border-semantic-border w-full rounded-md border p-2"
          placeholder="Enter project description"
          rows={3}
        />
      </div>
    </form>
  </CardContent>
  <CardFooter>
    <Button variant="outline">Cancel</Button>
    <Button>Create Project</Button>
  </CardFooter>
</Card>
```

## Accessibility

- **Semantic Structure**: Uses proper HTML elements for content organization
- **Keyboard Navigation**: Full keyboard support
- **Screen Readers**: Proper heading hierarchy and content structure
- **Focus Management**: Clear focus indicators

## Best Practices

1. **Use consistent spacing** with semantic tokens
2. **Provide clear hierarchy** with proper heading levels
3. **Keep content focused** - one main topic per card
4. **Use appropriate actions** in footers
5. **Test with screen readers** for accessibility
6. **Consider responsive design** for different screen sizes
