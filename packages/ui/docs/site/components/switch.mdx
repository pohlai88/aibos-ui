# Switch

Toggle switches for binary on/off states with smooth animations.

## Import

```tsx
import { Switch } from '@aibos/ui';
```

## Basic Usage

```tsx
<Switch>Enable notifications</Switch>
```

## Variants

### Default Switch

```tsx
<Switch>Default switch</Switch>
```

### Checked State

```tsx
<Switch defaultChecked>Pre-enabled option</Switch>
```

### Disabled State

```tsx
<Switch disabled>Disabled switch</Switch>
```

### With Labels

```tsx
<div className="flex items-center space-x-2">
  <Switch id="notifications" />
  <label htmlFor="notifications">Enable notifications</label>
</div>
```

## Form Integration

### Controlled Switch

```tsx
function ControlledSwitch() {
  const [enabled, setEnabled] = useState(false);

  return (
    <Switch checked={enabled} onCheckedChange={setEnabled}>
      Controlled switch
    </Switch>
  );
}
```

### Switch Group

```tsx
function SwitchGroup() {
  const [settings, setSettings] = useState({
    notifications: true,
    darkMode: false,
    autoSave: true,
  });

  const updateSetting = (key, value) => {
    setSettings((prev) => ({ ...prev, [key]: value }));
  };

  return (
    <div className="space-y-4">
      <div className="flex items-center justify-between">
        <div>
          <label className="text-sm font-medium">Push Notifications</label>
          <p className="text-semantic-muted-foreground text-sm">
            Receive push notifications on your device
          </p>
        </div>
        <Switch
          checked={settings.notifications}
          onCheckedChange={(checked) => updateSetting('notifications', checked)}
        />
      </div>

      <div className="flex items-center justify-between">
        <div>
          <label className="text-sm font-medium">Dark Mode</label>
          <p className="text-semantic-muted-foreground text-sm">Switch to dark theme</p>
        </div>
        <Switch
          checked={settings.darkMode}
          onCheckedChange={(checked) => updateSetting('darkMode', checked)}
        />
      </div>

      <div className="flex items-center justify-between">
        <div>
          <label className="text-sm font-medium">Auto Save</label>
          <p className="text-semantic-muted-foreground text-sm">Automatically save changes</p>
        </div>
        <Switch
          checked={settings.autoSave}
          onCheckedChange={(checked) => updateSetting('autoSave', checked)}
        />
      </div>
    </div>
  );
}
```

### Loading States

```tsx
function LoadingSwitch() {
  const [loading, setLoading] = useState(false);
  const [enabled, setEnabled] = useState(false);

  const handleToggle = async (checked) => {
    setLoading(true);
    // Simulate API call
    await new Promise((resolve) => setTimeout(resolve, 1000));
    setEnabled(checked);
    setLoading(false);
  };

  return (
    <div className="flex items-center space-x-2">
      <Switch checked={enabled} onCheckedChange={handleToggle} disabled={loading} />
      <span className="text-sm">{loading ? 'Updating...' : enabled ? 'Enabled' : 'Disabled'}</span>
    </div>
  );
}
```

## API Reference

### Switch Props

| Prop              | Type                         | Default | Description                         |
| ----------------- | ---------------------------- | ------- | ----------------------------------- |
| `checked`         | `boolean`                    | `false` | Controlled checked state            |
| `defaultChecked`  | `boolean`                    | `false` | Uncontrolled checked state          |
| `disabled`        | `boolean`                    | `false` | Whether the switch is disabled      |
| `onCheckedChange` | `(checked: boolean) => void` | -       | Callback when checked state changes |
| `className`       | `string`                     | -       | Additional CSS classes              |
| `children`        | `ReactNode`                  | -       | Switch label content                |

## Accessibility

- **Keyboard Navigation**: Focusable with Tab key, activated with Space
- **Screen Reader Support**: Proper ARIA attributes and labels
- **Focus Management**: Visible focus indicators
- **Disabled State**: Properly announced to screen readers
- **State Announcements**: Current state is communicated to assistive technology

## Best Practices

1. **Use clear labels** - Provide descriptive text for each switch
2. **Group related toggles** - Use consistent spacing and grouping
3. **Provide immediate feedback** - Show loading states for async operations
4. **Consider default states** - Set appropriate defaults based on user expectations
5. **Test with screen readers** - Ensure accessibility compliance
6. **Use for binary states** - Switches are ideal for on/off, enable/disable scenarios
