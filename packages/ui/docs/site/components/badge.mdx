# Badge

Status indicators and labels for displaying short pieces of information.

## Import

```tsx
import { Badge } from '@aibos/ui';
```

## Basic Usage

```tsx
<Badge>New</Badge>
```

## Variants

### Default Badge

```tsx
<Badge>Default</Badge>
```

### Status Variants

```tsx
<div className="flex gap-2">
  <Badge variant="default">Default</Badge>
  <Badge variant="secondary">Secondary</Badge>
  <Badge variant="destructive">Error</Badge>
  <Badge variant="outline">Outline</Badge>
</div>
```

### Size Variants

```tsx
<div className="flex items-center gap-2">
  <Badge size="sm">Small</Badge>
  <Badge size="default">Default</Badge>
```

### Interactive Badges

```tsx
function InteractiveBadges() {
  const [selected, setSelected] = useState([]);

  const tags = ['React', 'TypeScript', 'Node.js', 'Python', 'Go', 'Rust'];

  return (
    <div className="space-y-4">
      <h3 className="text-lg font-semibold">Select Technologies</h3>
      <div className="flex flex-wrap gap-2">
        {tags.map((tag) => (
          <Badge
            key={tag}
            variant={selected.includes(tag) ? 'default' : 'outline'}
            className="cursor-pointer hover:opacity-80"
            onClick={() => {
              if (selected.includes(tag)) {
                setSelected(selected.filter((t) => t !== tag));
              } else {
                setSelected([...selected, tag]);
              }
            }}
          >
            {tag}
          </Badge>
        ))}
      </div>

      {selected.length > 0 && (
        <div className="text-semantic-muted-foreground text-sm">
          Selected: {selected.join(', ')}
        </div>
      )}
    </div>
  );
}
```

## API Reference

### Badge Props

| Prop        | Type                                                     | Default     | Description            |
| ----------- | -------------------------------------------------------- | ----------- | ---------------------- |
| `variant`   | `'default' \| 'secondary' \| 'destructive' \| 'outline'` | `'default'` | Visual style variant   |
| `size`      | `'sm' \| 'default' \| 'lg'`                              | `'default'` | Size of the badge      |
| `className` | `string`                                                 | -           | Additional CSS classes |
| `children`  | `ReactNode`                                              | -           | Badge content          |

## Accessibility

- **Semantic Structure**: Uses appropriate HTML elements for content
- **Color Contrast**: Meets WCAG contrast requirements
- **Screen Reader Support**: Properly announced content
- **Focus Management**: Can be made focusable when interactive
- **Status Communication**: Clear visual and textual status indicators

## Best Practices

1. **Use appropriate variants** - Choose colors that match the content meaning
2. **Keep text concise** - Badges work best with short, clear text
3. **Consider context** - Use badges that fit the surrounding design
4. **Provide clear meaning** - Ensure badges communicate their purpose clearly
5. **Test color contrast** - Ensure accessibility compliance
6. **Use sparingly** - Don't overuse badges as they can create visual noise
