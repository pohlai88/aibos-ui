# Tooltip

Contextual information that appears on hover or focus to provide additional details.

## Import

```tsx
import { Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from '@aibos/ui';
```

## Basic Usage

```tsx
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger asChild>
      <Button variant="outline">Hover me</Button>
    </TooltipTrigger>
    <TooltipContent>
      <p>This is a tooltip</p>
    </TooltipContent>
  </Tooltip>
</TooltipProvider>
```

## API Reference

### TooltipProvider Props

| Prop                      | Type        | Default | Description                                               |
| ------------------------- | ----------- | ------- | --------------------------------------------------------- |
| `delayDuration`           | `number`    | `700`   | Delay before showing tooltip                              |
| `skipDelayDuration`       | `number`    | `300`   | Delay before showing tooltip when moving between triggers |
| `disableHoverableContent` | `boolean`   | `false` | Whether to disable hoverable content                      |
| `className`               | `string`    | -       | Additional CSS classes                                    |
| `children`                | `ReactNode` | -       | Tooltip content                                           |

### Tooltip Props

| Prop                      | Type        | Default | Description                                 |
| ------------------------- | ----------- | ------- | ------------------------------------------- |
| `delayDuration`           | `number`    | -       | Override provider delay duration            |
| `skipDelayDuration`       | `number`    | -       | Override provider skip delay duration       |
| `disableHoverableContent` | `boolean`   | -       | Override provider disable hoverable content |
| `className`               | `string`    | -       | Additional CSS classes                      |
| `children`                | `ReactNode` | -       | Tooltip content                             |

### TooltipTrigger Props

| Prop        | Type        | Default | Description                               |
| ----------- | ----------- | ------- | ----------------------------------------- |
| `asChild`   | `boolean`   | `false` | Whether to merge props with child element |
| `className` | `string`    | -       | Additional CSS classes                    |
| `children`  | `ReactNode` | -       | Trigger content                           |

### TooltipContent Props

| Prop          | Type                                     | Default    | Description                         |
| ------------- | ---------------------------------------- | ---------- | ----------------------------------- |
| `side`        | `'top' \| 'right' \| 'bottom' \| 'left'` | `'top'`    | Side of the trigger to show tooltip |
| `align`       | `'start' \| 'center' \| 'end'`           | `'center'` | Alignment of the tooltip            |
| `sideOffset`  | `number`                                 | `4`        | Distance from the trigger           |
| `alignOffset` | `number`                                 | `0`        | Alignment offset                    |
| `className`   | `string`                                 | -          | Additional CSS classes              |
| `children`    | `ReactNode`                              | -          | Tooltip content                     |

## Accessibility

- **Keyboard Navigation**: Tooltips appear on focus and disappear on blur
- **Screen Reader Support**: Proper ARIA attributes and announcements
- **Focus Management**: Clear focus indicators
- **Hover Behavior**: Tooltips appear on hover and disappear on mouse leave
- **Touch Support**: Tooltips work with touch devices

## Best Practices

1. **Keep content concise** - Tooltips should be brief and informative
2. **Use appropriate timing** - Set reasonable delay durations
3. **Provide meaningful content** - Ensure tooltips add value
4. **Test with screen readers** - Ensure accessibility compliance
5. **Consider mobile devices** - Test touch interactions
6. **Use sparingly** - Don't overuse tooltips as they can create clutter
