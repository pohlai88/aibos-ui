# Navigation

Site navigation components for organizing and accessing different sections of your application.

## Import

```tsx
import { Navigation, NavigationItem, NavigationList, NavigationTrigger } from '@aibos/ui';
```

## Basic Usage

```tsx
<Navigation>
  <NavigationList>
    <NavigationItem>
      <NavigationTrigger>Home</NavigationTrigger>
    </NavigationItem>
    <NavigationItem>
      <NavigationTrigger>About</NavigationTrigger>
    </NavigationItem>
    <NavigationItem>
      <NavigationTrigger>Contact</NavigationTrigger>
    </NavigationItem>
  </NavigationList>
</Navigation>
```

## Form Integration

### Controlled Navigation

```tsx
function ControlledNavigation() {
  const [activeItem, setActiveItem] = useState('dashboard');

  return (
    <Navigation>
      <NavigationList>
        <NavigationItem>
          <NavigationTrigger
            active={activeItem === 'dashboard'}
            onClick={() => setActiveItem('dashboard')}
          >
            Dashboard
          </NavigationTrigger>
        </NavigationItem>
        <NavigationItem>
          <NavigationTrigger
            active={activeItem === 'projects'}
            onClick={() => setActiveItem('projects')}
          >
            Projects
          </NavigationTrigger>
        </NavigationItem>
        <NavigationItem>
          <NavigationTrigger active={activeItem === 'team'} onClick={() => setActiveItem('team')}>
            Team
          </NavigationTrigger>
        </NavigationItem>
      </NavigationList>
    </Navigation>
  );
}
```

### Dynamic Navigation

```tsx
function DynamicNavigation() {
  const [menuItems, setMenuItems] = useState([
    { id: 'home', label: 'Home', icon: HomeIcon },
    { id: 'about', label: 'About', icon: InfoIcon },
    { id: 'contact', label: 'Contact', icon: MailIcon },
  ]);
  const [activeItem, setActiveItem] = useState('home');

  const addMenuItem = () => {
    const newId = `item-${menuItems.length + 1}`;
    setMenuItems([
      ...menuItems,
      {
        id: newId,
        label: `Item ${menuItems.length + 1}`,
        icon: PlusIcon,
      },
    ]);
  };

  return (
    <div className="space-y-4">
      <div className="flex items-center justify-between">
        <h3 className="text-lg font-semibold">Navigation Menu</h3>
        <Button onClick={addMenuItem}>Add Item</Button>
      </div>

      <Navigation>
        <NavigationList>
          {menuItems.map((item) => (
            <NavigationItem key={item.id}>
              <NavigationTrigger
                active={activeItem === item.id}
                onClick={() => setActiveItem(item.id)}
              >
                <item.icon className="mr-2 h-4 w-4" />
                {item.label}
              </NavigationTrigger>
            </NavigationItem>
          ))}
        </NavigationList>
      </Navigation>
    </div>
  );
}
```

## API Reference

### Navigation Props

| Prop          | Type                         | Default        | Description            |
| ------------- | ---------------------------- | -------------- | ---------------------- |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Navigation orientation |
| `className`   | `string`                     | -              | Additional CSS classes |
| `children`    | `ReactNode`                  | -              | Navigation content     |

### NavigationList Props

| Prop        | Type        | Default | Description            |
| ----------- | ----------- | ------- | ---------------------- |
| `className` | `string`    | -       | Additional CSS classes |
| `children`  | `ReactNode` | -       | List content           |

### NavigationItem Props

| Prop        | Type        | Default | Description            |
| ----------- | ----------- | ------- | ---------------------- |
| `className` | `string`    | -       | Additional CSS classes |
| `children`  | `ReactNode` | -       | Item content           |

### NavigationTrigger Props

| Prop        | Type         | Default | Description                     |
| ----------- | ------------ | ------- | ------------------------------- |
| `active`    | `boolean`    | `false` | Whether the trigger is active   |
| `disabled`  | `boolean`    | `false` | Whether the trigger is disabled |
| `onClick`   | `() => void` | -       | Click handler                   |
| `className` | `string`     | -       | Additional CSS classes          |
| `children`  | `ReactNode`  | -       | Trigger content                 |

## Accessibility

- **Keyboard Navigation**: Full keyboard support with arrow keys
- **Screen Reader Support**: Proper ARIA attributes and announcements
- **Focus Management**: Clear focus indicators and proper tab order
- **Disabled State**: Properly announced to screen readers
- **Active State**: Clear indication of current page/section

## Best Practices

1. **Use clear labels** - Provide descriptive navigation labels
2. **Group related items** - Organize navigation logically
3. **Consider mobile devices** - Ensure mobile-friendly navigation
4. **Provide visual feedback** - Show active/current state clearly
5. **Test with screen readers** - Ensure accessibility compliance
6. **Keep navigation consistent** - Maintain consistent navigation across pages
