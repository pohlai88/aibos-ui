# Toast

Notification messages that appear temporarily to provide feedback to users.

## Import

```tsx
import {
  Toast,
  ToastAction,
  ToastClose,
  ToastDescription,
  ToastProvider,
  ToastTitle,
  ToastViewport,
} from '@aibos/ui';
```

## Basic Usage

```tsx
<ToastProvider>
  <Toast>
    <ToastTitle>Success!</ToastTitle>
    <ToastDescription>Your changes have been saved successfully.</ToastDescription>
    <ToastClose />
  </Toast>
</ToastProvider>
```

## Form Integration

### Controlled Toast

```tsx
function ControlledToast() {
  const [toasts, setToasts] = useState([]);

  const addToast = (type, title, description) => {
    const id = Date.now();
    setToasts([...toasts, { id, type, title, description }]);

    // Auto remove after 5 seconds
    setTimeout(() => {
      setToasts((prev) => prev.filter((toast) => toast.id !== id));
    }, 5000);
  };

  return (
    <div className="space-y-4">
      <div className="flex space-x-2">
        <Button onClick={() => addToast('default', 'Success', 'Operation completed successfully')}>
          Success Toast
        </Button>
        <Button onClick={() => addToast('destructive', 'Error', 'Something went wrong')}>
          Error Toast
        </Button>
      </div>

      <ToastProvider>
        {toasts.map((toast) => (
          <Toast key={toast.id} variant={toast.type}>
            <ToastTitle>{toast.title}</ToastTitle>
            <ToastDescription>{toast.description}</ToastDescription>
            <ToastClose />
          </Toast>
        ))}
        <ToastViewport />
      </ToastProvider>
    </div>
  );
}
```

### Dynamic Toast

```tsx
function DynamicToast() {
  const [toasts, setToasts] = useState([]);

  const showToast = (type, title, description, action) => {
    const id = Date.now();
    const newToast = {
      id,
      type,
      title,
      description,
      action,
      timestamp: new Date().toLocaleTimeString(),
    };

    setToasts((prev) => [...prev, newToast]);

    // Auto remove after 5 seconds
    setTimeout(() => {
      setToasts((prev) => prev.filter((toast) => toast.id !== id));
    }, 5000);
  };

  const removeToast = (id) => {
    setToasts((prev) => prev.filter((toast) => toast.id !== id));
  };

  return (
    <div className="space-y-4">
      <div className="flex flex-wrap gap-2">
        <Button onClick={() => showToast('default', 'Success', 'Operation completed successfully')}>
          Success
        </Button>
        <Button onClick={() => showToast('destructive', 'Error', 'Something went wrong')}>
          Error
        </Button>
        <Button onClick={() => showToast('default', 'Info', 'Here is some information')}>
          Info
        </Button>
        <Button onClick={() => showToast('default', 'Warning', 'Please be careful')}>
          Warning
        </Button>
      </div>

      <ToastProvider>
        {toasts.map((toast) => (
          <Toast key={toast.id} variant={toast.type}>
            <ToastTitle>{toast.title}</ToastTitle>
            <ToastDescription>{toast.description}</ToastDescription>
            {toast.action && (
              <ToastAction altText={toast.action.altText}>
                <Button variant="outline" size="sm">
                  {toast.action.label}
                </Button>
              </ToastAction>
            )}
            <ToastClose onClick={() => removeToast(toast.id)} />
          </Toast>
        ))}
        <ToastViewport />
      </ToastProvider>
    </div>
  );
}
```

## API Reference

### ToastProvider Props

| Prop             | Type                                  | Default   | Description                |
| ---------------- | ------------------------------------- | --------- | -------------------------- |
| `swipeDirection` | `'up' \| 'down' \| 'left' \| 'right'` | `'right'` | Swipe direction to dismiss |
| `duration`       | `number`                              | `5000`    | Duration in milliseconds   |
| `className`      | `string`                              | -         | Additional CSS classes     |
| `children`       | `ReactNode`                           | -         | Toast content              |

### Toast Props

| Prop        | Type                         | Default     | Description            |

## Accessibility

- **Screen Reader Support**: Proper ARIA attributes and announcements
- **Keyboard Navigation**: Full keyboard support for interactions
- **Focus Management**: Clear focus indicators
- **Auto Dismiss**: Automatic dismissal with configurable duration
- **Swipe Gestures**: Support for swipe-to-dismiss on touch devices

## Best Practices

1. **Use appropriate variants** - Choose success, error, or default based on context
2. **Keep messages concise** - Toast messages should be brief and clear
3. **Provide actions when needed** - Include relevant actions like "Undo" or "View"
4. **Handle multiple toasts** - Manage stacking and ordering properly
5. **Test with screen readers** - Ensure accessibility compliance
6. **Consider timing** - Set appropriate auto-dismiss durations
