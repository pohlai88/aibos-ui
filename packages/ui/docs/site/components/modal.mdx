# Modal

A modal dialog component built on Radix UI with accessibility features, focus management, and semantic tokens.

## Import

```tsx
import { Modal } from '@aibos/ui';
```

## Basic Usage

```tsx
import { useState } from 'react';

function ModalExample() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Open Modal</Button>

      <Modal isOpen={isOpen} onClose={() => setIsOpen(false)}>
        <div className="p-6">
          <h2 className="mb-4 text-lg font-semibold">Modal Title</h2>
          <p className="text-semantic-muted-foreground mb-6">
            This is a basic modal dialog with content.
          </p>
          <div className="flex justify-end space-x-2">
            <Button variant="outline" onClick={() => setIsOpen(false)}>
              Cancel
            </Button>
            <Button onClick={() => setIsOpen(false)}>Confirm</Button>
          </div>
        </div>
      </Modal>
    </>
  );
}
```

### Form Modal

```tsx
function FormModal() {
  const [isOpen, setIsOpen] = useState(false);
  const [formData, setFormData] = useState({ name: '', email: '' });

  const handleSubmit = (e) => {
    e.preventDefault();
    console.log('Form submitted:', formData);
    setIsOpen(false);
  };

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Add User</Button>

      <Modal isOpen={isOpen} onClose={() => setIsOpen(false)}>
        <form onSubmit={handleSubmit} className="p-6">
          <h2 className="mb-4 text-lg font-semibold">Add New User</h2>

          <div className="mb-6 space-y-4">
            <div>
              <label className="text-sm font-medium">Name</label>
              <Input
                value={formData.name}
                onChange={(e) => setFormData({ ...formData, name: e.target.value })}
                placeholder="Enter name"
                required
              />
            </div>
            <div>
              <label className="text-sm font-medium">Email</label>
              <Input
                type="email"
                value={formData.email}
                onChange={(e) => setFormData({ ...formData, email: e.target.value })}
                placeholder="Enter email"
                required
              />
            </div>
          </div>

          <div className="flex justify-end space-x-2">
            <Button type="button" variant="outline" onClick={() => setIsOpen(false)}>
              Cancel
            </Button>
            <Button type="submit">Add User</Button>
          </div>
        </form>
      </Modal>
    </>
  );
}
```

## API Reference

### Props

| Prop                  | Type                   | Default | Description                             |
| --------------------- | ---------------------- | ------- | --------------------------------------- |
| `isOpen`              | `boolean`              | -       | Whether the modal is open               |
| `onClose`             | `() => void`           | -       | Function called when modal should close |
| `size`                | `"sm" \| "md" \| "lg"` | `"md"`  | Size of the modal                       |
| `children`            | `ReactNode`            | -       | Modal content                           |
| `className`           | `string`               | -       | Additional CSS classes                  |
| `closeOnOverlayClick` | `boolean`              | `true`  | Whether clicking overlay closes modal   |
| `closeOnEscape`       | `boolean`              | `true`  | Whether pressing Escape closes modal    |

## Accessibility

- **Focus Management**: Automatically traps focus within the modal
- **Screen Readers**: Proper ARIA attributes and announcements
- **Keyboard Navigation**: Full keyboard support (Tab, Escape, Enter)
- **Focus Restoration**: Returns focus to trigger element when closed
- **Overlay Interaction**: Proper handling of overlay clicks and focus

## Best Practices

1. **Always provide a way to close** the modal (close button, overlay click, Escape key)
2. **Use appropriate modal sizes** based on content complexity
3. **Provide clear headings** for screen reader users
4. **Test keyboard navigation** to ensure accessibility
5. **Consider mobile experience** with responsive sizing
6. **Use semantic tokens** for consistent styling
7. **Handle form submissions** properly within modals
